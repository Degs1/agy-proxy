Dokumen ini memetakan perbandingan antara **PRD Baseline** (`docs/PRD.md`), **Requirements Document** (`docs/contract/requirements.md`), dan **Approved Design** (`docs/contract/approved-design.md`). ## 1. Matriks Rekonsiliasi Keputusan Arsitektur dan Bisnis

| Topik & Aspek | PRD Baseline (`docs/PRD.md`) | Requirements (`requirements.md`) | Approved Design (`approved-design.md`) | Status Keputusan | Konsensus & Keputusan Final |
|---|---|---|---|---|---|
| **AI Provider Aktif MVP** | Target utama Antigravity; fallback resmi Gemini API jika Antigravity belum terverifikasi. | Gemini API resmi adalah satu-satunya provider aktif MVP. Antigravity berstatus `unsupported`. Fork 9Router bukan dependensi. | Adapter modular dengan implementasi aktif Gemini API resmi. Antigravity berstatus `unsupported` sampai izin inferensi dan OAuth terverifikasi resmi. | **Terkunci (Final)** | **Gemini API resmi menjadi provider aktif tunggal untuk MVP.** Antigravity ditandai `unsupported` / `pending_verification`. Kode fork 9Router tidak diimpor. |
| **Arsitektur Deployment** | Next.js Monolith + Serverless di Vercel; MongoDB Atlas. | Next.js App Router dan TypeScript di Vercel terhubung langsung ke MongoDB Atlas; tanpa VPS atau router terpisah. | Monolith Next.js App Router di Vercel langsung ke Atlas; tanpa service proxy eksternal, tanpa Docker Compose lokal. | **Terkunci (Final)** | **Aplikasi tunggal Next.js App Router di Vercel ke MongoDB Atlas.** Pengembangan lokal langsung ke Atlas tanpa Docker Compose atau Redis. |
| **Koordinasi & Transaksi State** | Operasi atomik MongoDB untuk shared state; rate limiting dan lease concurrency. | Atlas wajib mendukung transaksi multi-dokumen. Serialisasi via dokumen penjaga project dengan waktu server Atlas. | Transaksi multi-dokumen Atlas dengan penjaga per-project (`project_guards`) dan waktu server Atlas sebagai sumber acuan tunggal. | **Terkunci (Final)** | **Semua mutasi admission, rate limit, dan concurrency menggunakan transaksi multi-dokumen Atlas** dengan single source of truth waktu server Atlas. |
| **Batas Rate Limiting** | Multi-layer: Global, Project RPM, Project Concurrency, Account Concurrency. | Project RPM: 60 req/menit UTC (jendela tetap detik :00). Project Concurrency: 5 slot aktif per project. | Jendela tetap 1 menit UTC detik 00; kuota default 60 RPM; slot concurrency default 5 per project. Dihitung atomik dalam transaksi. | **Terkunci (Final)** | **Fixed window 1 menit UTC (60 RPM) dan 5 concurrent request per project.** Admin dapat mengubah batas menjadi bilangan bulat positif. |
| **Concurrency & Siklus Lease** | Lease-based reservation dengan ID, Project, Account, dan expiration. | Masa berlaku lease 45 detik dari waktu transaksi server Atlas; perpanjangan sekurangnya tiap 15 detik. | Lease unik 45 detik; diperpanjang tiap 15 detik selama aktif; dianggap kedaluwarsa tepat pada `expires_at`; pemulihan mandiri tanpa menunggu TTL. | **Terkunci (Final)** | **Lease 45 detik, heartbeat perpanjangan 15 detik.** Jika proses mati atau timeout, lease yang ditinggalkan tetap aktif hingga mencapai waktu kedaluwarsa (`expires_at`); slot concurrency dipulihkan pada transaksi admission pertama yang tiba setelah `expires_at` terlampaui (tanpa menunggu proses background TTL Atlas). |
| **Idempotensi & Sidik Request** | Hindari duplicate-key race pada reservasi paralel. | Kombinasi unik `(project_id, api_key_id, Idempotency-Key)`. UUID wajib. Sidik request SHA-256 kanonis. | Sidik SHA-256 mencakup model alias, messages, stream, temperature, max_tokens; abaikan urutan key JSON dan normalisasi angka/stream. | **Terkunci (Final)** | **Idempotensi ketat berbasis UUID per API key.** Sidik payload deterministik. Retry payload berbeda menghasilkan `409 idempotency_conflict`. Retry terminal menghasilkan `409 request_already_processed` dengan metadata `outcome`. |
| **Validasi Ukuran Body** | Ukuran request dibatasi untuk keamanan. | Ukuran body JSON maksimal 1 MiB (1.048.576 byte). Pelanggaran menghasilkan HTTP 413 `payload_too_large`. | Streaming parser atau buffer validator memotong pada 1 MiB; mengembalikan HTTP 413 dengan `param: null`. | **Terkunci (Final)** | **Batas keras 1 MiB (1.048.576 byte).** Lebih dari 1 MiB ditolak dengan HTTP 413 dan kode `payload_too_large`. |
| **Struktur & Batas Messages** | Field `messages` dan `model` wajib; peran standar OpenAI. | 1 sampai 64 pesan. Tiap konten maksimal 32 KiB UTF-8. Urutan: system awal opsional -> user pertama -> assistant/user bergantian -> user akhir. | Validasi skema Zod ketat: panjang array 1..64, konten 1..32768 byte, pola peran percakapan valid. Pelanggaran menghasilkan HTTP 400 `invalid_request`. | **Terkunci (Final)** | **1..64 pesan, konten 1..32 KiB per pesan.** Urutan peran wajib berakhir dengan `user`. Pesan `system` hanya boleh di awal. |
| **Parameter Numerik & Opsional** | `temperature`, `max_tokens`, `top_p`, `stream`, `stop`. | Parameter yang diterima MVP HANYA: `model`, `messages`, `stream`, `temperature` (0..2), `max_tokens` (1..8192). | Field OpenAI lain (`tools`, `functions`, `n`, dll.) ditolak eksplisit dengan HTTP 400 `unsupported_feature`. `stream` default `false`. | **Terkunci (Final)** | **Hanya 5 field tingkat atas yang diizinkan.** Field luar cakupan MVP ditolak tegas dengan kode `unsupported_feature`, tidak diabaikan diam-diam. |
| **Autentikasi Admin & CSRF** | Auth.js, secure HTTP-only cookies, brute-force protection. | Admin awal via bootstrap script terproteksi dengan Argon2id. Sesi cookie `__Host-admin_session` (12 jam maks, 30 mnt idle). CSRF via `X-CSRF-Token` + `Origin`. | Bootstrap transaksional dengan dokumen guard unik. Mutasi admin wajib mencocokkan `Origin` dan `X-CSRF-Token` sesi. Rate limit login 5/email & 20/IP per 15 mnt. | **Terkunci (Final)** | **Tidak ada public signup.** Autentikasi sesi cookie aman berawalan `__Host-`, proteksi CSRF double-check (`Origin` + header token), dan pembatasan login terdistribusi. |
| **Model Alias & Credential Binding** | Konfigurasi mapping model publik ke upstream model. | Project memiliki alias `gemini-default`. Alias terikat eksplisit ke 1 credential Gemini aktif milik project yang sama. | Skema alias menyimpan `actual_model` dan `credential_id` milik project yang sama. Tidak ada rotasi atau fallback credential lintas project. | **Terkunci (Final)** | **Alias model terikat 1:1 ke credential aktif milik project yang sama.** Pemisahan tegas multi-tenant project; pergantian model tidak mengubah kontrak publik. |
| **Format Error Publik** | Format OpenAI `{ error: { message, type, code } }`. | Format standar `{ error: { message, type, param, code } }`. Error terpetakan konsisten untuk 400, 401, 403, 404, 409, 413, 429, 502, 503, 504. | Bentuk error tunggal konsisten di seluruh endpoint gateway. Untuk SSE mid-stream, dikirim sebagai event `data: {"error":...}\n\n` lalu `[DONE]`. | **Terkunci (Final)** | **Format error OpenAI kanonis dengan field `param`.** Error pasca-koneksi SSE ditransmisikan dalam stream sebelum ditutup. |
| **Logging & Privasi Data** | Catat metadata, dilarang simpan prompt/respons/credential, retensi 30 hari. | Dilarang mencatat isi pesan atau respons. Pra-autentikasi dicatat maksimal 1.000/menit dengan retensi 7 hari. Catatan operasional project memiliki retensi terkelola. | Koleksi `request_logs` (hanya metadata performa dan token) dan `preauth_rejections` (agregat/cuplikan terbatas rate). Indeks TTL otomatis. | **Terkunci (Final)** | **Zero payload logging.** Tidak ada logging prompt, completion, key, atau token bearer di serverless logs maupun database. |
| **Batas Runtime Vercel** | Kompatibel dengan durasi Vercel; Free/Pro/Enterprise trade-off didokumentasikan. | Target durasi eksekusi 660 detik diverifikasi melalui probe mandiri sebelum rilis. | Konfigurasi `maxDuration` 660 detik pada route gateway; bukti runtime dicatat di `docs/evidence/runtime-vercel.md`. | **Terkunci (Final)** | **660 detik disyaratkan untuk streaming jangka panjang.** Evaluasi paket target menjadi gerbang kelayakan sebelum rilis MVP. |
